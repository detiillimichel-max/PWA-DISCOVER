# PWA-DISCOVER 🌎🌀

Primeira fundação do DISCOVER.

## V1 — Fundação

- PWA responsivo para celular e computador.
- Catálogo JSON local.
- Busca somente no catálogo local.
- Cache local da busca.
- Service Worker para funcionamento offline básico.
- Nenhuma API externa é consultada na abertura.
- Nenhum Supabase.
- Nenhuma integração com o Telegrafo nesta fase.
